# cleanup.test.js timing flake — root cause + fix

- **Timestamp (UTC):** 2026-05-25
- **Failing test:** `cleanupStaleArtifacts › respects maxAgeMs option`
- **Symptom (sample run):** `Expected values to be strictly equal: + 970 - 969`

## Root cause

The test called `cleanupStaleArtifacts({ dryRun: true, maxAgeMs: ... })`
twice and asserted `result1.scanned === result7.scanned`. Both calls
read the production `./runs/` directory via the module-load constant:

```ts
const RUNS_DIR = process.env["CRUCIBULUM_RUNS_DIR"] ?? join(process.cwd(), "runs");
```

Other tests in the suite (release-gauntlet, model-certify, conversational
runner, etc.) write run bundles to that same directory in parallel. Between
the two `readdirSync(RUNS_DIR)` calls, a single bundle file could appear or
disappear — making `scanned` differ by exactly 1 on flaky runs. The test
was correct in spirit (the option should not change the scan target) but
brittle because the scan target was shared, mutable global state.

## Fix applied (deterministic, not quarantine)

1. **`core/cleanup.ts`** — added an injectable `runsDir` option on
   `cleanupStaleArtifacts` (and pass-through on `getCleanupStats`).
   The module-load constant was replaced with `resolveRunsDir(override)`
   evaluated per call:

   ```ts
   function resolveRunsDir(override?: string): string {
     if (override) return override;
     return process.env["CRUCIBULUM_RUNS_DIR"] ?? join(process.cwd(), "runs");
   }
   ```

2. **`tests/cleanup.test.ts`** — uses `mkdtempSync` to create a
   self-contained `runs/` directory per `describe` block, seeded with
   exactly 5 deterministic entries (2 `ws_*` dirs, 2 `run_*.json` files,
   1 unrelated `notes.md`). Both `maxAgeMs` calls run against the same
   temp dir; assertion `scanned === 5` now holds across parallel runs.

Backward-compat preserved: callers that don't pass `runsDir` still
read the production directory or honour `CRUCIBULUM_RUNS_DIR`.

## Commands run

```bash
npm run build                                       # tsc clean
for i in 1..5; do node --test dist/tests/cleanup.test.js; done
# 5/5 → 4 pass · 0 fail (was: occasionally 3 pass · 1 fail)
```

## Result

PASS — deterministic across 5 consecutive runs. The flake is fixed
without quarantine.
