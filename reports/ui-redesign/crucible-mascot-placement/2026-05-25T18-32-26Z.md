# Crucible — mascot placement correction

- **Timestamp (UTC):** 2026-05-25T18-32-26Z
- **Operator:** Zen
- **Branch:** master
- **Predecessor pass:** `crucible-leaderboard-first-layout/2026-05-25T18-20-33Z.md`

## Before-issue summary

Squidley was tucked into the bottom `.deck-footer-seal` as a 28 px image
at `opacity:.5; filter:grayscale(.4) brightness(.85)`. Effect:

- buried below the entire deck and almost invisible against the dark
  footer background;
- the top command rail used a generic `⌬` glyph as the brand emblem,
  giving Crucible no recognizable brand personality;
- the operator scrolled past the entire arena to reach the only
  Squidley on the page, and even then it was barely visible.

## Mascot placement

Replaced the `⌬` glyph in the cmd-rail brand cluster with a small
Squidley image. The deck-footer image was removed since the header
mascot is now the primary, visible brand mark.

```
┌───────── cmd-rail ─────────────────────────────────────┐
│ [Squidley 52px]  LATEST RUN · JUDGE DECK   [chips...]  │
│                  CRUCIBLE                              │
│                  Evaluation Arena                      │
└────────────────────────────────────────────────────────┘
```

The brand column was already 48 px wide for the old glyph — the 52 px
image just fills that slot, so the header card's height does not
grow. Mascot is decorative-only (`aria-hidden="true"`, empty `alt`,
`pointer-events:none`).

### Size / opacity

| viewport       | width × height | opacity | filter                                                    |
|----------------|----------------|---------|-----------------------------------------------------------|
| desktop ≥ 900px | 52 × 52 px    | 0.88    | `drop-shadow(0 0 6px rgba(34,211,238,.35))` + soft shadow |
| 600–899 px     | 44 × 44 px     | 0.88    | same                                                      |
| < 600 px       | 40 × 40 px     | 0.88    | same                                                      |
| `prefers-reduced-motion` | — | — | filter cleared                                              |

`object-fit: contain` keeps the aspect ratio; no halo, no rotation
animation, no oversized hero treatment.
