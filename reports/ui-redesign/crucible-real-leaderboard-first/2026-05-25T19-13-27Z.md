## What was wrong before

The previous "leaderboard-first" pass added a small top-3 champion
strip (`renderRankingDeck`) but the **actual full leaderboard** —
"Ranked Model Comparison" with simple / table / chart toggle, JSON /
CSV export, and click-through drilldown — stayed buried inside the
Active Arena (`renderDashboard` and `renderLane` both still called
`renderRankedResults`). The operator saw a 3-up teaser at the top and
had to scroll past the entire arena to reach the real ranking.

## Exact component moved

`renderRankedResults(tabKey)` — the full leaderboard component that
already existed and was already rendered inside the arena — was
hoisted into a new top-of-page deck-window.

| Before | After |
| --- | --- |
| `renderDashboard` called `renderComparisonBars('Overall Model Ranking', …) + renderRankedResults('dashboard')` inside the arena | both calls removed; comment marks them as hoisted |
| `renderLane(tab.key)` called `renderLaneLeaderboardGraph(tab.key) + renderRankedResults(tab.key)` inside the arena | both calls removed; comment marks them as hoisted |
| Top of page rendered `renderRankingDeck()` — a 3-up teaser only | Top of page renders `renderRealLeaderboardZone()` — a deck-window wrapping the **full** `renderRankedResults(tabKey)` plus a compact champion strip header |

## What teaser was removed / demoted

- `renderRankingDeck()` (the old teaser-only function) was deleted.
- The 3-up champion cards still exist — but now as a small `<div
  class="champion-strip">` header **inside** the new
  `renderRealLeaderboardZone` deck-window, with the full ranked-rows
  body immediately below. There is no longer a teaser separate from
  the real leaderboard.

## Leaderboard width / readability result

- The zone uses `class="deck-ranking-zone real-leaderboard-zone"` and
  the CSS rule `.full-leaderboard-zone{width:100%; min-width:0}` —
  the zone spans the full `min(96vw, 1760px)` deck-shell width.
- The hoisted ranked-rows inside the zone use a wider grid:
  `grid-template-columns:36px minmax(360px,1.6fr) minmax(160px,2fr)
  60px minmax(60px,auto)` so the model column gets at least **360 px**
  on desktop. Long ids (`deepseek/deepseek-v4-pro`,
  `google/gemini-3.1-flash-lite`) render on a single line at 1440 px
  and wider; at tablet widths the floor relaxes to 280 px and the id
  wraps to 2 lines if needed.
- The wide model column is sufficient at 1920 px to show ALL of:
  `xiaomi/mimo-v2-pro`, `qwen3.5:9b`, `google/gemini-3.1-flash-lite`,
  `xiaomi/mimo-v2-flash`, `google/gemini-3.5-flash`,
  `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v4-pro` without
  any truncation.

## Side-card redistribution

- Score Distribution: no longer competes with the leaderboard for
  width — the leaderboard sits in its own dedicated full-width zone
  ABOVE the deck grid. Score Distribution stays inside `renderRuns`
  (called only when expanded), so it shows up in the lower Run
  History area, not beside the leaderboard.
- Failure Board, Provider Bay, Evidence Vault, Release Gate stay in
  the right rail of the deck grid, unchanged.
- Quick Picks and "How To Read Results" remain in the dashboard side
  column.
- Focused Run / Bundle Trace / Test Review Explorer stay inside the
  arena (these are deep evidence views that load only when a model is
  drilled into).

## Model selector / run button placement

Unchanged from the previous pass — they live inside the Active Arena
in `renderLaneCommandTop` with the order:

1. Tests picker
2. Adapter / Provider routing
3. Certification banner
4. **Model selector** (`.cc-model-select`, full width, ≥ 200 px tall)
5. Run count
6. **Action grid** (RUN BENCHMARK / RUN ALL spanning 2 cells each,
   LOCAL / CLOUD / REFRESH wrap-friendly)

Since the leaderboard is now ABOVE the arena, the model selector
sits visibly below the leaderboard on every viewport.

## Remaining UI debt

- **Score Distribution placement** — currently inside `renderRuns`
  (Run History). For users who never expand Run History the
  distribution chart is invisible. A future pass could promote a
  compact histogram into the leaderboard zone footer, or into the
  right rail as a small side-deck.
- **renderLaneLeaderboardGraph and renderComparisonBars are now
  unreachable from the active UI** — they're still defined (used by
  the providers tab and other places) so removing them would break
  the providers view. Keep as-is until a separate cleanup pass.
- **Champion strip vs full-table** — on very wide monitors (≥ 2560
  px) the champion strip + full table can look top-heavy. A future
  pass might add an option to collapse the champion strip when the
  table is at full height.

## Honesty preserved

- The leaderboard is now the FIRST content block after status. There
  is no teaser substitute — the real ranked rows render at the top.
- The full model id is shown in the row text AND in the `title=`
  hover tooltip.
- PROVISIONAL chip stays in the deck header when `<3` runs in scope.
- Champion crown shows the current #1's full (truncated to 28 chars)
  model id; the rank card below shows the un-truncated id.
- Certified / Uncertified labels are still in the cmd-rail and the
  Provider Bay / Release Gate decks.
