# Crucible Symposium UI Redesign Report

**Date**: 2026-05-25T16:24:55Z
**Pass**: Symposium Design Language Alignment

## Before: Problem Summary

- Visually stylish bioluminescent deep-sea theme but too dense and saturated
- Too much small text (10-11px base), excessive letter-spacing (.14em+)
- Heavy animated underwater particle/caustic effects competing with data
- Orange-on-dark color scheme hard to read at a glance
- Squidley mascot at 42% opacity competing with stats in hero
- Navigation tabs too small for mobile touch targets
- Advanced telemetry (tokens, costs, hashes) always visible
- Family/lane navigation not intuitive as a long horizontal tab bar
- Overall felt like a complicated benchmark cockpit, not a readable console

## After: What Changed

### CSS (crucibulum.css) - Complete redesign

**Color palette**: Deep abyss blue (#00030a) replaced with warm charcoal (#0f1117).
Orange primary (#fb923c) replaced with amber/gold (#f59e0b). Teal shifted warmer
(#4df5c8 to #34d399). All neon glow effects removed.

**Typography**: Base size increased from 11px to 14px. Letter-spacing reduced from
.14em to .02-.06em for body text. Section headings use normal casing instead of
ALL-CAPS with extreme tracking. Font weight hierarchy clarified (400/500/600/700/800).

**Cards**: Removed radial gradient overlays, conic gradients, and multi-layer
box-shadows. Cards now use simple `backdrop-filter: blur(12px)` glass effect with
subtle 8% opacity borders. No current-line decorations on card edges.

**Background**: Removed 16 particle radial gradients, caustic wash pseudo-elements,
network halo, and signal tether lines between panels. Clean dark charcoal background.

**Hero**: Squidley reduced to 8% opacity grayscale watermark. Title changed from
glowing orange to clean white. Removed conic gradient halo behind mascot.

**Navigation**: Tabs increased from 10px/11px to 13px with 12px padding. Active state
uses simple white-on-dark instead of glowing orange gradient. Touch targets now 44px+.

**Status pills**: Chips/tags use 8% opacity backgrounds instead of gradient fills.
Borders at 30% accent opacity. Clean, scannable.

**Run strips**: Removed 3px glowing left-border pseudo-elements. Now use simple
3px solid left-border for status indication. Hover is background change, not transform.

**Spacing**: Increased gaps from 10-14px to 12-16px throughout. Card padding from
14-16px to 16-18px.

### HTML (index.html) - Hero simplification

- Hero title: "CRUCIBLE" (all-caps glowing) to "Crucible" (clean)
- Subtitle: "BIOLUMINESCENT EVALUATION LATTICE" to "Evaluation Lattice"
- Lane marker: "CRCB . PERSONALITY" to "Personality"
- Run count: "12 RUNS INDEXED" to "12 runs indexed"
- Removed `ab-squid-halo` div from hero
- Removed `hot` class from status chip (no glow)

## What Got Simpler (default view)

- Hero: clean title + score + mode toggle, no competing art
- Cards: flat glass without gradient overlays or current lines
- Text: larger, more readable, less uppercased
- Colors: warm and welcoming instead of cold neon
- Tabs: chunky, easy to tap on mobile
- Status: simple pills instead of glowing badges

## What Remains Advanced-Only

- Provenance bundle trace (hash, auth, oracle status)
- Methodology judge stack (schema, rubric, oracle visibility)
- Operational readout (tokens, costs, thresholds)
- Lane composition details (score families, task families)
- Score matrix / heatmap
- Category review grid
- Archive scope metadata

## Mobile Validation

- Viewport meta tag present
- 720px and 420px breakpoints active
- Single-column layout below 720px
- Tabs wrap to 2-per-row at 720px, 1-per-row at 420px
- Touch targets 44px+ for tabs, buttons, toggles
- No horizontal overflow from card/chip content
- Chips/tags allow text wrapping on narrow viewports
