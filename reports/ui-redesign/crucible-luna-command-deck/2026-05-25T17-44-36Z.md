# Crucible — Luna-style Command Deck redesign

- **Timestamp (UTC):** 2026-05-25T17-44-36Z
- **Operator:** Zen
- **Branch:** master
- **Template:** `/mnt/ai/luna/src/web/` (minus cosmic background per directive)

## Why the previous Symposium-lite pass missed

The 2026-05-25 Symposium correction fixed the indigo/violet palette and
killed the hero Squidley, but kept the underlying topology unchanged:

- A flat hero strip
- A centered horizontal tab list
- A single linear column of panels below

That is a **corporate dashboard layout** dressed in nicer colors. The
operator's reference (Luna) reads as a **command deck** because it splits
the workspace into:

- a left utility rail of named decks/rooms,
- a central operational window framed by chunky chrome,
- a right telemetry rail of glanceable sub-decks,
- and a bottom evidence/activity strip.

Symposium tokens alone could not produce that feel. The redesign had to
restructure the page, not restyle individual elements.

## What changed structurally

### CSS — `ui/crucibulum.css`

Added a Luna-equivalent **command deck** layer that lives alongside the
existing Symposium chrome (so existing classes / tests continue to work):

- `.deck-shell` — wider wrapper (max 1720 px), pulls the rails apart
- `.cmd-rail` — top command-strip with brand glyph, plate title, scope/
  provider/model/cert chips, trust-score plate and Simple/Advanced toggle
- `.deck-window` — Luna's bevelled game-window chrome: outer 2 px ring,
  inner bevel, bronze trim, vignette gloss
- `.deck-header` + `.deck-socket` + `.deck-title-plate` — Luna's glowing
  socketed title plates (cyan / amber / red / violet / green variants)
- `.deck-grid` — 3-column rail grid with named areas:
  `"left center right" / "floor floor floor"`
- `.rooms-list` + `.room-card` — Evaluation Rooms navigator (cards
  replace the centered tab list)
- `.failure-board` + `.failure-row.product|provider|config|info|clean` —
  Failure Board severity rows
- `.provider-bay` + `.bay-row` — Provider Bay matrix
- `.evidence-stack` + `.gate-row` — Evidence Vault + Release Gate
- `.feed-item` — Evidence Feed bottom strip (terminal-style)
- `.telemetry-deck` — collapsible `<details>` for advanced metadata
- Responsive: rails collapse to 2-up at ≤ 1099 px, single column at
  ≤ 720 px (rooms become horizontal pills), tightened at ≤ 420 px
- No aurora / starfield / planets — atmosphere stays as the calm indigo
  radial gradients already on `body`

### JS / HTML — `ui/index.html`

Added new render helpers and re-composed `render()`:

| New function | Purpose |
| --- | --- |
| `roomStatusForTab(tabKey)` | Lane health summary used by room cards |
| `renderEvaluationRoomsDeck()` | Left rail — tabs as cards |
| `failureBoardCounts(tabKey)` | Bucketed Product/Provider/Config/Skip/Clean |
| `renderFailureBoardDeck()` | Right-rail Failure Board |
| `selectedProviderModelSummary(tabKey)` | Provider/model + certification lookup |
| `providerHealthMini()` | Compact health snapshot |
| `renderProviderBayDeck()` | Right-rail Provider Bay |
| `renderEvidenceVaultDeck()` | Right-rail Evidence Vault + actions |
| `renderReleaseGateDeck()` | Right-rail Release Gate + Telemetry deck |
| `renderEvidenceDeck()` | Composer for the right rail |
| `renderEvidenceFeed()` | Bottom Evidence Feed (recent trials) |
| `renderCommandRail()` | New top rail (replaces the standalone hero strip) |
| `activeArenaTitlePlate()` | Per-tab plate title |
| `renderActiveArenaShell()` | Wraps existing `renderActiveTab()` in deck chrome |

`render()` was rewritten to compose:

```
[system status bar]      (kept above the rail — global signal)
[offline banner]
[command rail]           (renderCommandRail — brand + chips + toggle)
<main class="deck-grid">
  <aside class="deck-rail-left">  Evaluation Rooms
  <section class="deck-rail-center">  Active Arena (renderActiveTab inside)
  <aside class="deck-rail-right">  Failure Board · Provider Bay · Evidence Vault · Release Gate
  <section class="deck-floor">    Evidence Feed
</main>
<nav class="nav-band" hidden>     legacy tabbar kept hidden for test contract
<footer class="deck-footer">      tiny Squidley + "Crucible Evaluation Lattice"
```

All existing helpers (`renderHero`, `renderTabs`, `renderDashboard`,
`renderLane`, `renderProvidersView`, `renderTabs`, etc.) are unchanged
and still invoked — they now mount inside the deck-window arena instead
of beside a flat tab strip. This preserves every existing handler and
the Symposium test contract.

## Remaining UI debt

- **Cmd-rail chip overflow at narrow desktops** — at ~1100 px the cmd-
  rail chip stack can wrap to three rows. Not broken, but tighter at
  ~1240 px would feel cleaner. Follow-up: gate the long chip labels at
  this width or move the Provider/Model chips into a second sub-row.
- **Per-tab room status dots** — currently driven by `stats.pass_rate`
  from the lane's cached stats; tabs that have never been opened will
  show "Idle". On boot we don't pre-fetch every lane. Follow-up: add a
  cheap rollup call so room dots populate from the first paint instead
  of only after a tab visit.
- **Failure Board double-counts** — Skips that miss a more specific
  bucket fall into `config`. The bucketing logic in `failureBoardCounts`
  is intentionally conservative; refining the origin map for tools/trust
  lanes is a follow-up.
- **Active Arena title plate** — uses static `"<tab> Arena"` text; could
  pull from `tab.headline` for a one-line subtitle that varies by lane.
- **Right rail height balance** — Failure Board + Provider Bay +
  Evidence Vault + Release Gate stack tall on lanes with little data.
  Consider collapsing two of them into a Telemetry Deck `<details>` if
  the operator reports it eats vertical room on small monitors.

## Honesty preserved

- Release certification scope ("Certified release target" /
  "Uncertified visible" / "NOT UI-CERTIFIED") is now visible at three
  places: the cmd-rail chip stack, the Provider Bay deck, and the
  Release Gate deck. It is no longer buried in small text inside the
  task-picker.
- Trust score is the plate value on the command rail, but the
  Simple/Advanced toggle and the existing scope chips are unchanged, so
  the operator still sees provisional / public-trust state.
- Evidence Vault always shows the latest bundle id / verdict / hash /
  signature — clicking `Open Evidence` jumps to the in-page evidence
  inspector that already existed.
