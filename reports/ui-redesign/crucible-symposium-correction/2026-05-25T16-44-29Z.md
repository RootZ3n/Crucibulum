# Crucible Symposium UI Correction Report

**Date**: 2026-05-25T16:44:29Z
**Pass**: Symposium Visual Language Correction

## Why Previous Pass Missed

The first redesign made Crucible cleaner but converted it to a generic flat
charcoal SaaS dashboard. The operator compared mobile screenshots and said
"No where near the same. Total miss."

Specific failures:
- **Too flat/dark/corporate**: Warm charcoal (#0f1117) with white borders
  looked like any corporate dark theme, not Symposium's sci-fi lab feel.
- **No visual identity**: Lost the playful personality. Symposium uses
  purple/indigo glass surfaces with cyan neon accents and pink highlights.
- **Weak card treatment**: Cards were flat with rgba(255,255,255,.08) borders
  instead of Symposium's visible violet-tinted glass containers.
- **Boring navigation**: Tab pills were generic gray-on-dark instead of
  Symposium's chunky violet-glow active states.
- **No color personality**: Orange-as-primary was replaced with amber-on-gray,
  losing the spectrum. Symposium uses violet/cyan/pink as its identity.

## What Changed (Correction)

### Color palette: Charcoal -> Indigo

| Token | Previous (miss) | Corrected |
|-------|-----------------|-----------|
| `--bg-0` | `#0f1117` (gray) | `#0c0a1a` (deep indigo) |
| `--bg-1` | `#151822` | `#130f28` |
| `--bg-card` | `rgba(28,32,48,.72)` | `rgba(22,18,52,.78)` |
| `--border-subtle` | `rgba(255,255,255,.08)` | `rgba(139,92,246,.15)` |
| `--ink` | `#e2e8f0` (blue-gray) | `#f0eaff` (warm lavender) |
| `--cyan` | `#67e8f9` (pale) | `#22d3ee` (vivid) |
| `--violet` | `#a78bfa` (accent only) | `#8b5cf6` (primary surface) |
| `--magenta` | `#f472b6` (unused) | `#ec4899` (highlight) |

### Card treatment: Flat -> Glass

- Cards now use violet-tinted `rgba(139,92,246,.06)` backgrounds
- Borders use `rgba(139,92,246,.15)` violet instead of white
- Active tabs glow with `linear-gradient(135deg,rgba(139,92,246,.35),rgba(139,92,246,.2))`
- Hero has `var(--glow-violet)` box-shadow aura
- Radial gradients on body give depth (violet top, pink bottom-right, cyan left)

### Hero: Flat header -> Mission console card

- Violet radial gradient aura at top of card
- Cyan-to-violet-to-magenta neon top accent line
- Score uses cyan with `text-shadow: 0 0 12px rgba(34,211,238,.3)`
- View toggle active state uses violet gradient with glow
- Lane label in cyan accent color

### Navigation: Gray pills -> Violet glow pills

- Active tab: white text on violet gradient with `0 0 16px rgba(139,92,246,.2)` glow
- Hover: violet tint `rgba(139,92,246,.08)`
- Background of tabbar: `rgba(139,92,246,.04)` for warm tint

### Status rail: Detached card -> Integrated strip

- Rounded indigo glass with violet tint
- `backdrop-filter: blur(16px)` for glass feel
- Sticky with `border-radius` (not flat strip)

### Score bars: Gray -> Violet spectrum

- Default fill: `linear-gradient(90deg,var(--cyan),var(--violet-hot))`
- Ranked rows 4+: `linear-gradient(90deg,var(--violet),var(--magenta-hot))`
- Background tracks: `rgba(139,92,246,.1)` instead of `rgba(255,255,255,.06)`

### Buttons: Generic -> Neon

- Primary: violet-to-pink gradient with glow shadow
- Secondary: cyan tint with cyan border
- Active run-count: white on violet background
- Filter chip active: violet-hot text on violet background
