## 4 · New skip / integrity classifiers

Two new codes in `core/skip-classifiers.ts`:

| Code | When |
|---|---|
| `SKIPPED_FIXTURE_HASH_MISMATCH` | Fixture file exists but its sha256 disagrees with the manifest pin. Distinct from `FAIL_PRODUCT` because no model was exercised — this is a fixture-integrity problem (regenerate or update the manifest). |
| `SKIPPED_IMAGE_TRANSPORT_UNSUPPORTED` | Model declares vision capability but no adapter knows how to encode the image for this provider yet. Distinct from `SKIPPED_UNSUPPORTED_MULTIMODAL` (model-side gap) because the model COULD answer if the wire format existed. |

Both carry the standard skip-policy flags (`countsAsFail:false`,
`affectsLeaderboard:false`, `affectsCertification:false`). Both are
included in `scripts/model-certify.mjs SKIP_CODES` so tier
classification filters them out cleanly.

## 5 · Fixture validation behavior (preflight)

`preflightSkipCheck(manifest, capabilities, { fs })` now performs a
five-step precedence walk for vision tasks:

1. **`SKIPPED_FIXTURE_MISSING`** — manifest sha256 starts with `TBD`
2. **`SKIPPED_FIXTURE_MISSING`** — fs check: file doesn't exist
3. **`SKIPPED_FIXTURE_HASH_MISMATCH`** — fs check: bytes don't match pin
4. **`SKIPPED_UNSUPPORTED_MULTIMODAL`** — model lacks `supportsVision` + `supportsImageInput`
5. **`SKIPPED_IMAGE_TRANSPORT_UNSUPPORTED`** — model has capability but adapter has no image transport

Every check happens BEFORE any provider call. Pinned by tests V5-V9.

The conversational runner now injects a `REPO_FS` handle so the
integrity check runs against the real disk during a normal run.
Helper: `verifyFixtureOnDisk(fs, manifestImageFixture)` returns a
structured `FixtureCheck` (`OK | MISSING_FILE | HASH_MISMATCH |
READ_ERROR`) that the runner translates into the right skip code.

## 6 · Unsupported multimodal behavior

Unchanged from Phase 2 plus the new transport gate:

- Non-vision model on a vision task → `SKIPPED_UNSUPPORTED_MULTIMODAL`
- Vision-capable model on a vision task where the adapter has no
  image transport → `SKIPPED_IMAGE_TRANSPORT_UNSUPPORTED`

Both produce zero-spend skip bundles with `verdict.completionState:
"SKIPPED"` and full capability snapshot embedded for audit.
