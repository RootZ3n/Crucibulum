## 1. API endpoint path

`GET /api/capabilities/vision/promotion-evaluation` (new, in
`server/routes/capabilities-vision.ts`, wired in `server/app.ts:194`).

The route is **GET-only by design**. No POST/PUT/PATCH path is
registered for any of:

- `/api/capabilities/vision/promotion-evaluation`
- `/api/capabilities/vision/promote`
- `/api/capabilities/vision/promotion`
- `/api/capabilities/vision/certify`
- `/api/capabilities/promote`

Method-routing is exact-match-by-(path,method) in
`server/app.ts`; any other method on the registered path falls to
the catch-all 404. The new Phase 13-C P2 + P3 tests assert this
end-to-end against a live `createApp()` instance.

## 2. Routes evaluated

The endpoint hand-curates three Vision routes (preferred / legacy /
comparison) and calls `evaluatePromotion()` (pure function, no
mutation) for each tier:

| Provider | Model | Role |
|---|---|---|
| `openrouter` | `xiaomi/mimo-v2.5` | `preferred_daily_driver_candidate` |
| `openrouter` | `xiaomi/mimo-v2-omni` | `legacy_proven_fallback` |
| `openai` | `gpt-5.4-mini` | `comparison_route` |

For each route, evidence is loaded from the most-recent matching
stability report under
`reports/capability-expansion/vision-stability/` (ISO-Z stamps so
lexicographic-sort = chronological; the loader picks the newest
file whose `provider` + `model` fields match). When no stability
report exists for a route, the loader emits an
`evidence-missing` blocker for every per-tier decision rather than
crashing — Phase 13-C test P14 asserts this end-to-end by
temporarily renaming the stability dir and re-hitting the
endpoint.

## 4. CAPABILITY_CERTIFIED blockers

`CAPABILITY_CERTIFIED` is **blocked on every route**, by design.
The doctrine gates surface two structural conditions today:

- `vision.capability-certified.suite-size` — the Vision suite has
  5 tests; the doctrine requires 15. Roadmap Phase C addresses
  this.
- `vision.capability-certified.independent-routes` — each
  stability run profiles one route; the doctrine requires 3
  independent route families. Roadmap Phase E addresses this.

Both blockers appear on every route's
`capabilityCertifiedDecision.blockingReasons` array. Phase 13-C
test P12 asserts this — the doctrine evaluator never lets the
current state of Vision become CAPABILITY_CERTIFIED, even though
every individual route now meets PROVIDER_TESTED and STABLE.

This is precisely what the doctrine is supposed to do: prevent
premature certification on small suites + single routes,
regardless of how clean the smoke evidence looks.

## 6. No-mutation confirmation

- **Pure function evaluator.** `evaluatePromotion()` in
  `core/capability-certification.ts:149` is a pure function:
  it returns a `CapabilityPromotionDecision` payload; it never
  writes to any registry. The endpoint calls it three times per
  route (PROVIDER_TESTED, STABLE, CAPABILITY_CERTIFIED) and
  serialises the responses verbatim.
- **No new write paths.** Phase 13-C adds exactly one route line in
  `server/app.ts` and exactly one handler file
  (`server/routes/capabilities-vision.ts`). The handler imports
  only `existsSync`, `readdirSync`, `readFileSync` from
  `node:fs` — read-only file APIs.
- **Method-routing assertion.** Phase 13-C tests **P2** and **P3**
  fire POST/PUT/PATCH/DELETE against the registered path and
  several plausible write-phase URLs against the server; every
  response is 404.
- **Per-decision literal-false flags.** Every nested
  `providerTestedDecision`, `stableDecision`, and
  `capabilityCertifiedDecision` carries
  `affectsLeaderboard:false`, `affectsCertification:false` —
  Phase 13-C tests P6 + P7 assert this for every route.
- **Top-level guarantees.** `experimental:true`,
  `promoted:false`, `affectsLeaderboard:false`,
  `affectsCertification:false`, `noMutationGuarantee:true`,
  `promotionRequiresFutureWritePhase:true`,
  `currentTier:"EXPERIMENTAL"`.
- **Evidence resilience.** P14 hides the entire stability dir and
  re-hits the endpoint; the response is still 200 and every
  per-tier decision surfaces an `evidence-missing` blocker
  instead of crashing.
