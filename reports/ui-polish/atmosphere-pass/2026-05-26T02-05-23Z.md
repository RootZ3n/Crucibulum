## TL;DR

Added four additive depth layers via `body::before`,
`body::after`, and a `:root --shadow-molten` token consumed by the
existing `.panel / .subpanel / .metric-card / .result-card / .deck-window`
selectors. The UI now reads like a high-tech evaluation deck
suspended over a molten forge — top corners darken into chamber
walls, a warm forge bloom rises from below the viewport, and cards
get a soft warm under-glow against the cool cyan/violet UI lights.
A single 14-second ambient-pulse animation (opacity 0.88 → 1.00,
ease-in-out, alternate) gives the forge a slow distant breath; it's
disabled under `prefers-reduced-motion`. No card moved, no rule
was deleted, no layout breakpoint shifted.

## Layers added

| # | Layer | Implementation | Visual role |
|---|---|---|---|
| L1 | Existing body background base | unchanged (`html,body { background: var(--bg-0); background-image: <existing violet/pink/cyan radials> }`) | Crucible's identity glass tint — kept as-is |
| L2 | Deep chamber + molten forge bloom | `body::before { position:fixed; inset:0; z-index:0 }` with **three** stacked radial gradients: hot forge core at `ellipse 90% 55% at 50% 108%` (rgba 255,110,50 → transparent), broader warm wash at `50% 115%`, top corner-darkening vignette at `50% 0%` | Heat rising from below + chamber walls falling away above |
| L3 | Midground haze veil | `body::after { position:fixed; inset:0; z-index:0 }` with a single linear gradient: `transparent → rgba(120,50,25,0.04) → rgba(160,70,30,0.06)` at the bottom 55–100% | Subtle warm haze between chamber and cards (no blend mode, so it cannot reach text) |
| L4 | Panel rim warmth | `:root { --shadow-molten: 0 14px 32px -18px rgba(255,90,30,.20), inset 0 1px 0 rgba(255,170,90,.03) }` consumed via `.panel,.subpanel,.metric-card,.result-card,.deck-window { box-shadow: var(--shadow-panel), var(--shadow-molten) }` | Cards now drop a warm under-shadow + carry a 1-px warm rim highlight |

Stacking guarantees:
- `body::before` and `body::after` sit at `z-index:0`.
- `#app` is already `z-index:1` with `position:relative`.
- All app content paints **above** the atmosphere, so neither layer
  can lift `body::after` over text — readability is preserved by
  construction, not by tuning.

## Animations added

**One.** A very slow ambient pulse on the chamber gradient:

```css
@keyframes crucibleEmberBreathe {
  0%   { opacity: 0.88; }
  100% { opacity: 1.00; }
}
body::before {
  animation: crucibleEmberBreathe 14s ease-in-out infinite alternate;
}
@media (prefers-reduced-motion: reduce) {
  body::before { animation: none; opacity: 0.94; }
}
```

Cycle: 14 s, ease-in-out, alternate (no visual reset), 12-percentage-
point opacity delta. Effectively invisible during active reading —
the operator notices the chamber feels "alive" only at the periphery
of their attention. Disabled entirely under `prefers-reduced-motion`.

No other animations were added. No fire-licking, no spark
particulates, no flashing.
