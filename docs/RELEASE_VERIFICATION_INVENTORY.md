## Runner modes
- `runTask` → repo-based (workspace, diff, judge, scored bundle)
- `runConversationalTask` → conversational (chat loop, per-question
  deterministic scoring, evidence bundle)
- `handleRunPost` IIFE catch → minimal failure bundle for pre-execution
  failures (health-check / adapter-init / preflight rejection)
